## 1. 方向：一個外框、一套元件、兩層資訊

**問題**（需求第 4 節）：概念多、驗收面板長到交件被推到第 2 個畫面以後、knowledge-kit 與 AI 員工各有一套寫法。

**v4 的三個做法**

1. **一個外框**：每一頁都是「頁首（主標題＋一句說明＋動作）→ 分頁（需要時）→ 內容」。AI 員工的子頁不再是「AI 員工＋虛構資料」標題列，而是和 knowledge-kit 一樣每頁一個主標題（例如「工作與驗收」），上方小字「AI 員工」表示所在區塊。分頁元件在待審、上傳、AI 員工共用；手機上同一個元件改為可橫向捲動，目前的分頁自動捲到中間。
2. **一套元件**：卡片、清單列、徽章、按鈕、表單、揭露列、空狀態、對話框各只有一種寫法（第 5 節）。
3. **兩層資訊**：預設只顯示做決定需要的東西（第一層）；說明、經過與統計收成一行，需要時展開（第二層）；完整紀錄在其他頁（第三層，工作帳本、信任）。**不拿掉任何功能**，每個收起的東西都有一行摘要告訴你那裡有什麼。

延續 v3：墨與螢光、黃色只代表出處、未通過不做整片紅底、AI 標記＋職務圖示。

## 4. 外框與導覽

### 桌機（≥ 720px）

- **側欄 232px**：字標（範例公司）＋「最近的變化」鈴鐺（數字是未讀的變化）；首頁、問答、圖譜、時間軸、上傳、待審｜AI 員工（數字＝待驗收）、評測台；底部「虛構資料・展示用權限」與身分卡（點了打開身分與語言）。
- 寬度 720～980px：側欄縮成 72px 的圖示列，數字移到圖示右上角。
- **內容區**最大 1200px（AI 員工與問答 1320px），左右 32px。

### 手機（< 720px）

- **頂端列**：字標、「虛構資料」、最近的變化、身分（頭像）。
- **底部分頁列 5 格**：首頁、問答、圖譜、**AI 員工**、更多（時間軸、上傳、待審、評測台）。現況把 AI 員工放在「更多」；v4 建議放到底部，因為它是 knowledge-crew 的主要工作。**需要決定**（第 9 節）。
- AI 員工的 6 個子頁用同一個分頁元件，橫向捲動，目前的分頁置中。驗收面板的決定列固定在底部分頁列上方。

### 頁首（每頁一個）

```
[小字：所屬區塊，例如「AI 員工」]
主標題 h1（28px；手機 22px）             [頁面動作]
一句說明（muted，最多 68 字寬）
[分頁]
```

### 身分切換與最近的變化

- 身分與語言：一個對話框（手機為底部面板），三張身分單選卡＋語言；以展示帳號登入時不能切換（沿用現行規則）。`01-home.html#s=identity`
- 最近的變化：側欄與頂端列的鈴鐺連到首頁的「最近的變化」。內容與工作帳本相同的事件（看重點被收回或自動改回、守則等確認、抽查結果、退回），只列最近 4 則。

## 5. 元件

顏色全部來自 `client/theme.json`；只新增一個 token（見本節最後）。

| 元件 | 規格 |
| --- | --- |
| 卡片 | `surface` 底、1px `border`、16px 圓角、24px 內距（手機 16）；`card--tight` 16px；`card--flush` 內含清單時不留內距 |
| 卡片標題 | h2 17px 粗體＋同一行的 13px 說明（`meta`）＋右側動作 |
| 清單列 | 一列＝標題一行＋說明一行（＋狀態一行），說明以「・」分隔、可換行；列與列之間 1px 分隔線，**不是每列一個框**；選取中＝`raised` 底＋左側 3px 墨色線；尾端放 chevron、徽章或一個小按鈕 |
| 數字徽章 | 中性計數＝`raised` 底；需要你處理的數＝`primary` 底 |
| 徽章 | 外框 pill：逐項看（`muted` 框）、看重點（`success` 框與字）、抽查（墨色**虛線**框＋圖示）、已通過（`success`）、事後更正／已退回（`danger`）、安靜（`raised` 底，用於內部、專案） |
| AI 標記 | 17px 高、等寬字「AI」、1px 目前文字色的框；放在名字前 |
| 期限 | 「11/18 到期・已逾期」`danger` 粗體；「即將到期」`warning` 粗體；一般 `fg` |
| 按鈕 | 主要（`primary` 底，一個區塊最多一個）、次要（`borderStrong` 框）、墨色（不可撤回的動作：確定退回、記下更正）、文字按鈕；高度 40（觸控 44），小按鈕 32（觸控 44）。**不用停用樣式表示「還不能送出」**，改為送出時說明缺什麼 |
| 分段按鈕 | 逐條回饋（沒問題／有問題、做到／沒做到）、首頁篩選；按下＝墨色底 |
| 表單 | 標籤在上、說明在下；錯誤＝欄位 `danger` 框＋下方 `danger` 文字＋圖示；表單頂端「還差 N 項」摘要，每項連到欄位 |
| 單選卡 | 身分、交辦對象、退回原因、登入帳號共用；選中＝墨色 2px 框 |
| 揭露列 | 一行摘要＋chevron（`details/summary`），展開後內縮；摘要要說出裡面有什麼（例如「經過與把關・抽查 1 次（做錯了 1）」） |
| 狀態列（驗收的模式） | 一行：圖示＋粗體模式名＋一句說明＋動作；看重點＝`success` 框；抽查＝墨色虛線框；這次逐項看＝一般框 |
| 結論 | 圖示＋17px 粗體一句（未通過 `danger`、檢查中 `warning`）＋一句說明；沒有問題時不顯示 |
| 重點列 | 22px 墨色實心圓編號＋重點（可點）＋位置；守則用墨色外框方形＋書籤圖示，前面寫「依照的守則・」 |
| 檢查列 | 未通過：1px `danger` 框＋✕＋名稱與說明＋「未通過」；通過：一行，勾＋名稱＋「通過」 |
| 交件 | 以原本的樣子呈現：回信（寄給、主旨、段落）、條目（欄位）、程式（檔案清單）；左欄標示位置與「已修改：…」；手機改為上下排列 |
| 決定列 | 問句（「這封信可以寄出嗎？」）＋退回＋通過；桌機 `sticky` 在面板底部，手機固定在底部分頁列上方 |
| 空狀態 | 大：虛線框＋圖示＋標題＋原因＋最多兩個下一步；**行內**：一行虛線框（「問過的問題　還沒有問過問題」），用在次要區塊 |
| 表格 | 標題列下 1px 墨色線；數字靠右、等寬數字；**可以點的數字＝藍色粗體底線**，不能點的是一般文字；手機改為每列一張（`data-label`） |
| 信任時間軸 | 沿用 v3：10 欄、事件列、圓點列、層級帶；抽查＝圓點外加墨色外框；事後更正＝空心綠圓 |
| 變化列 | 圖示＋等寬日期＋一句話 |
| 對話框 | 桌機置中 560px；手機為底部面板；標題、內容、右下動作 |
| 導覽卡 | 一行：說明＋「開始導覽」＋關閉 |

**新增 token：`borderStrong`**（輸入框、次要按鈕、虛線收起區的框）。Light `#7E8691`（對 `surface` 3.68:1）、Dark `#5A6782`（對 `surface` 3.19:1），符合 WCAG 1.4.11 的 3:1。現況在程式中以字面值處理輸入框邊框（#153），v4 建議收進 `theme.json`。其他 token 不改。

**字級**：12（徽章）、13（說明）、14（次要內文）、15（內文）、16（交件本文，行高 1.85）、17（卡片標題）、22～24（面板標題）、28（頁面主標題）。

**英文**：按鈕與徽章不設固定寬度；清單的說明行允許換行；表格在 720px 以下改為上下排列；頁首動作在空間不夠時換到下一行。實作時以英文跑一次 `e2e/english-layout.spec.ts`。

## 6. 分層顯示與概念的安排

### 三層

| 層 | 放什麼 | 例 |
| --- | --- | --- |
| 第一層（預設看到） | 做決定需要的：結論、重點、檢查結果、交件、決定 | 驗收面板 |
| 第二層（一行摘要，展開才看） | 為什麼、怎麼算、經過、統計、收起的欄位與變更 | 「為什麼是看重點」「經過與把關」「數字怎麼算」 |
| 第三層（其他頁） | 完整紀錄 | 工作帳本、信任時間軸 |

**例外**：四項必要功能的**入口與說明**都在第一層（抽查狀態列、看重點狀態列的一句說明、信任頁的規則列、已完成工作的「通過後發現有錯…」）。

### 第一次來的人先看到什麼

| 時機 | 概念 | 怎麼出現 |
| --- | --- | --- |
| 第一次來 | 交辦、驗收、要看的重點、自動檢查、退回原因、信任 | 5 步導覽 |
| 開始用之後 | 守則 | 第一次在面板看到「依照的守則」時；員工頁 |
| 第一次遇到時 | 看重點、抽查、事後更正、逐條標記、知識的來歷 | 該元件自己的一行說明（狀態列、對話框的影響說明、「逐條標記」按下後的提示） |
| 需要追查時 | 工作帳本 | 從信任、結果卡、最近的變化連過去 |

### 導覽：8 步改 5 步（`tour-steps.ts`）

1. **今天的工作**（首頁）：交件在這裡等你驗收，有檢查沒通過的排前面。
2. **驗收面板**：最上面是結論與員工自己說的重點，旁邊是獨立檢查，下面是交件。
3. **退回的原因**：三選一，只有「做錯了」影響信任；意見可以記成守則。
4. **信任**：改看重點要你同意、可以收回；看重點期間每 5 件抽 1 件；做錯了自動改回。
5. **回流知識庫**：通過的條目與守則進入知識庫，原文標出經過什麼把關。

導覽卡改為一行（「第一次來？用 5 步看懂…大約 1 分鐘」）。原本的「守則」「抽查」「事後更正」三步改由第 3、4 步帶到，加上元件自己的說明。

## 7. 每個畫面

網址都相對於 `screens/`。

### 00 登入　`00-signin.html`
- 頂端列：字標、「虛構資料」「展示用權限」、語言。左側一段話說明 AI 員工做什麼、不做什麼（回應專家檢視 G1）；右側登入面板。
- 帳號是單選卡（帳號＋身分＋看得到什麼）；密碼欄停用並以虛線標示「展示版不需要密碼」；「登入」一直可以按，邀請碼錯誤時在欄位下說明。
- 手機：登入面板在上，說明在下。
